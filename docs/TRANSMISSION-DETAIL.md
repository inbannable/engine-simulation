# RS3 / DQ500 变速箱细化 · 2026-09-08

在现有 EA855 evo 模型与动力系统上增量修改，保留工作区已有发动机与外壳。

## 实物与结构参考

- [Gear Works：Audi RS3 DQ500 拆解说明](https://www.gearworks.it/portfolio-items/cambio-dsg-7-marce-audi-rs3-dq500-una-bomba/)：双输入轴、湿式离合器、液压拨叉与轴承等总成组成。
- [DQ500 拆解实物照片](https://www.barsegar-kfz.de/getriebeinstandsetzung/dsg/dq500-0bt-0bh)：斜齿轮、轴承与紧凑轴系的外观参考；这是 DQ500 家族 0BT/0BH，不能作为 RS3 0DL 的尺寸测量依据。
- [VW SSP454 原厂培训材料转载](https://manualzilla.com/doc/6317515/la-bo%C3%AEte-dsg-%C3%A0-double-embrayage-%C3%A0-7-rapports)：沿用既有双输入轴、双输出轴和倒挡路径。齿比与资料分级见 POWERTRAIN.md。

没有获得原厂 CAD 或带标尺的实物测量。24°螺旋角、20°压力角、齿数、轴距、七片离合器展示片数及间隙都是教学参数。使用渐开线齿廓和分层螺旋扫掠改善外观，不构成制造级齿面接触或装配干涉验证；运动齿比仍以动力学配置为准。

## 模型变化

- 七挡和倒挡从直齿示意改为渐开线斜齿，有齿根、齿顶、齿侧和端部倒角；输入/从动轮采用相反旋向，倒挡从二挡自由轮中转。
- 增加独立接合齿、同步锥环、同步毂、拨叉槽两侧肩部，以及输入/输出轴的滚子轴承。
- K1/K2 离合器改为径向嵌套，增加鼓体轴向花键与环形压紧活塞。钢片跟随发动机鼓体，摩擦片跟随输入轴，片间距随接合程度收缩。
- 保留原有外壳与剖切模式；所有新增模型由 build_transmission.py 重复生成并导出 Blender/GLB。

## 操作与时序

- N → D/R 先经过拨叉准备，再交接离合器；准备期不传递轮端扭矩。
- 更换预选挡时，等待同一离合器对应的其他同步套回中，以及目标同步套到达 ±7 mm，再报告接合。仍保留 50 mm/s 行程限速和最低同步准备时间。
- 离合器扭矩份额使用 smoothstep，交接开始与结束的命令斜率为零。
- 控制面板增加四组同步套的实时行程和接合状态，配合既有慢放、暂停、单步与 M 挡升降挡观察。

## 验证

18 项自动测试涵盖原有发动机、七挡/R、连续换挡、预选改选、方向互锁、超转保护、帧率无关性及 GLB 动画节点。新增断言检查挂挡前无驱动扭矩、同步套到位后才能交接，以及斜齿/离合器片元数据。

离线生成总成、剖切、内部机构与交接姿态四张渲染，人工检查内部机构和剖切。交接图为静态示意，不是求解器录制。未进行浏览器自动交互或性能测量。TypeScript 使用 `--incremental false` 避免工作区已有缓存文件写入错误。
